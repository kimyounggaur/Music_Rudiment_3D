2026-10-28 16:14 UTC. 기존 작성 작업은 사용자 승인으로 보관되고 마지막 실행이 interrupted임을 확인한 뒤 한 작성자만 원본에 통합했다. 범위는 첫 두 펼침면 미리보기판이다. 펼침면3–6은 이 1차 운영 배포를 확인한 뒤 구현한다.

## 보존과 수정

원본 HEAD `4dd62db8dc46ca6468bffeeb586c1d295a38a793`와 최초 114파일을 다시 대조했다. 원본의 tracked/untracked 202파일을 ZIP으로 보존하고 모든 항목 SHA256을 재검증했다. `.git`, 비밀 설정, 자격 증명, 의존성·캐시·빌드·QA 출력은 복사하지 않았다. 백업 ZIP SHA256은 `501742179116e761555af68f026ddac24ff5d15f0d33535757f52235bcba12d3`이다. 백업과 원시 QA는 로컬 작업공간에 보존하며 저장소에는 이 요약만 포함한다.

각 패치를 `git apply --check` 후 적용했다. 원본 결과와 별도 검증본의 대상 파일 해시가 같았다.

- 종이 바깥쪽이던 모서리 hit 영역을 실제 종이 안쪽 44 CSS px 영역으로 옮겼다. 투영 quad 역변환을 사용하며 실제 활성 페이지의 입력을 안정된 main owner에 위임한다.
- 학습 조작물·양식·편집 영역·스크롤바의 우선권은 유지한다. 방향·장면·인쇄 준비·포인터 owner 조건과 disabled/커서 표시가 같은 guard를 사용한다.
- 페이지 진행·release·hold·cancel 알고리즘은 바꾸지 않았다. pointer capture loss는 취소 경로로 정리한다.
- 책갈피의 44px 상자를 viewport 안으로 제한했다. 종이·카메라 투영은 바꾸지 않았다.

## 실제 확인 범위

검증본 `http://127.0.0.1:4283/?validation=drag-hit-fix-ccfaac06`에서 일반 버튼·키보드와 읽기 전용 DOM 계측을 사용했다. 거부된 자동 드래그 JavaScript를 재시도하거나 다른 URL/도구로 우회하지 않았다.

- 15:49:11 UTC 사용자 수동 확인이 전달됐다. **이 확인은 수정본의 잡기·끌어서 넘기기만 해당**한다. 원본 대화는 저장소에 복사하지 않는다.
- 키보드 탐색과 native 입력·slider 소유권, 3회 왕복 후 같은 편집 IDs, reload/resume 복원, import preview/cancel의 원문 유지와 confirm 복원을 확인했다.
- 재생 중 탐색 후 0.65초 이내 source0 및 page-exit 이유를 확인해 자연 종료와 구분했다. 닫기 후 source0도 확인했다. 실제 청취 증거는 아니다.

## 남은 검증과 릴리스 경계

최신 입력 위임 코드에서 정지 유지·역방향 취소를 사용자가 확인한 것으로 확대하지 않는다. 물리 휴대전화 touch, 실제 스피커/헤드폰 청취, Safari/iOS, 실제 보조기술·교육자 수용, 원본과의 동일 연속 입력 체감 비교는 미검증이다. 과거 곡면 hold/cancel 자료와 현재 순수 테스트는 최신 수동 확인의 대체가 아니다.

이 제한을 유지한 첫 두 펼침면 배포는 사용자가 명시 승인했다. 원격 main의 기준 SHA와 기존 Vercel Git 연동을 재확인했으며 설정·보호·자격 증명은 바꾸지 않았다. 새 릴리스 결과는 push 후 정확한 원격 SHA, CI, Vercel READY와 운영 화면을 실제 확인한 다음 별도로 기록한다.
