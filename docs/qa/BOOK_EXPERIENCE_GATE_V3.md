# 책 경험 관문 v3 (G1-C, 부록 B)

**정체성 5항목: 불일치 0 · 의도적 차이 0 · 미관측 5(원본 녹화 없음).** 원본과의 비교는 결정 6(원본 화면 녹화)이 제공되지 않아 하지 못했다. 그래서 정체성 항목은 모두 **미관측**이며, 미관측은 통과가 아니다. 아래 'v3 자체 기준' 열은 설계서가 적은 판정 기준을 v3 화면에서 잰 결과로, 원본 일치를 뜻하지 않는다. 그 가운데 1번(먼/가까운 변 비율), 2번(390×844의 종이 음영 측정), 3번(서 있는 모서리 선 폭)은 수치 기준을 일부 채우지 못했다 — 숨기지 않고 아래에 적는다. 수치는 R9 기준선(`refactor/R9/baseline/matrix.json`, ink, 펼침면 1)이다.

판정 값: **일치**(원본과 같은 시퀀스를 나란히 보고 같다고 판단) / **의도적 차이**(사유가 계약·결정에 있음) / **불일치**(원본과 다름, 고칠 것) / **미관측**(원본 비교를 하지 못함). 원본 녹화가 생기면 `docs/reference/original/`(저장소 밖, 경로만 기록)에 두고 같은 시퀀스 — 열린 책 → 레슨 1 → 그림 등장 → 샷 → Next → Previous — 를 나란히 비교해 이 표를 다시 판정한다. 검수 칸은 [사람 검수 패킷](HUMAN_REVIEW_V3.md) 1장.

기준: [설계서 v3 부록 B](../REFACTOR_DESIGN_V3.md), [계약 v3](../CONTRACT_V3.md), [모션 비교표](MOTION_COMPARISON.md), [단계 기록](../BUILD_STATUS_V3.md). 캡처 환경: Linux 컨테이너, headless Chromium 1243(SwiftShader WebGL), DPR 1 — 실기기 결과가 아니다.
