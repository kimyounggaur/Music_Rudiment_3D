## npm 레지스트리 연결 실패 — 부모 실행 기록

```powershell
npm view react version --fetch-retries=0 --fetch-timeout=10000
```

- 대상: npm 레지스트리 `registry.npmjs.org`의 React 메타데이터 조회.
- 결과: 종료 코드 `1`.
- 오류: `ENOTFOUND getaddrinfo registry.npmjs.org`.
- 상태: 실패 확인. 패키지 설치는 수행하지 않았다.
- 설명: DNS 이름 확인 실패로 관찰되었다. 이 기록만으로 네트워크 정책의 세부 원인을 단정하지 않는다.
- 제한: 사용자가 권한 확대를 별도 허용하지 않았으므로 escalation 또는 우회 경로를 사용하지 않았다. 자동 승인 심사 거부가 발생했다고 주장하는 것이 아니다.

## 추가 환경 관찰 — 담당자 직접 확인

- 기본 `py.exe`/`python.exe`는 WindowsApps 별칭이며 실행 불가였다. 실제 Python `3.14.3` 실행 파일을 찾아 버전 실행을 확인했고 부모에게 전달했다. Python 런타임 부재는 현재 장애 원인이 아니다.
- `npm cache ls`에서 React/TypeScript/Vite/Three/VexFlow/Playwright 일치 항목을 찾지 못했다.
- `npm config get cache`는 `The cache option is protected, and cannot be retrieved in this way`로 거부되었다. 해당 조회를 재시도하거나 npm 설정·로그를 읽지 않았다.
- 로컬 Chromium 실행 파일은 있으나 브라우저 검증은 실행하지 않았다.
- 자세한 경로와 점검 명령은 [REPO_AUDIT.md](../REPO_AUDIT.md)에 있다.
