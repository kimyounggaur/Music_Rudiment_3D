# 사람 검수 패킷 v3 (X07) — 외부 검수 대기

갱신: R9-a. 이 문서는 **검수할 사람에게 넘길 준비물**이다. 외부 연락·초대·공유는 하지 않았다. 모든 '실제 결과'·'날짜' 칸은 비어 있고 판정은 **대기**다. 빈칸을 통과로 채우지 않는다.

- 대상 코드: 브랜치 `refactor/v3-ink-book`(R9 정리 뒤 커밋). 로컬 실행: `npm ci && npm run dev` → `http://127.0.0.1:4173/`(3D 기본, 조작바 '크게 읽기' = 2D 책). 품질은 `?quality=low|medium|high`로 고정할 수 있다.
- 자동 검사로 이미 확인한 것과 그 한계: [BUILD_STATUS_V3.md](../BUILD_STATUS_V3.md), [책 경험 관문 v3](BOOK_EXPERIENCE_GATE_V3.md), [모션 비교표](MOTION_COMPARISON.md). headless SwiftShader 캡처는 실기기 통과가 아니다.
- 판정 값: **통과**(기대와 같음) / **수정**(고칠 것이 있음 — 무엇을 봤는지 '실제 결과'에) / **대기**(아직 안 봄).
