# R2 과도기 오차: HTML 쪽 겹침 vs 곡면 종이

R1–R2 동안 정지 펼침면의 글자는 HTML 겹침이다. HTML 요소는 곡면 종이의 네 모서리에 homography로 맞춰지므로 **모서리에서는 정확**하고 내부에서는 평면으로 남는다.

- 곡면 프로필: 거터 dip 0.08, bulge 0.055, 가장자리 droop 0.01(세계 단위, 진폭 1). 펼침면 1의 오른쪽 쪽은 진폭 1(묶음 0.172), 왼쪽 쪽은 0.135(묶음 0.018).
- 오른쪽 쪽 s≈0.45에서 곡면 높이 +0.044, 모서리 사이 직선 보간 −0.048 → 차이 약 0.092 세계 단위.
- 1280×720 원근(고도 62°, 화면 약 122 px/단위)에서 수직 투영 약 0.092 × cos 62° × 122 ≈ **5 px**. 844×390에서는 약 2.6 px.
- 넘김 중에는 HTML이 숨고 인쇄 텍스처(같은 곡면 기하)를 쓰므로 이 오차가 없다.

판정: 과도기 허용(설계서 R2 위험 a). R3에서 정지 쪽도 인쇄 텍스처가 되면서 사라진다. 통과 조건에서 제외한다.
