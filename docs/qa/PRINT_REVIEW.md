## 도구와 검증 한계

시스템 Python 3.14.3에는 `pypdf`, `pdfplumber`, `fitz`, `pymupdf`, `pypdfium2`, `PIL`이 없었다. `pdftotext` 명령도 확인되지 않아 시도한 텍스트 bbox 추출은 미실행 상태로 남았다. 설치는 시도하지 않았다. Poppler 렌더링 자체는 종료 코드 0으로 성공했다.

모든 검수는 로컬 PNG 화면을 눈으로 확인한 범위다. 실제 프린터의 비인쇄 영역, 실제 종이·흑백 인쇄, 접근성 태그·스크린리더, 음악교사 검수는 수행하지 않았다. 원본 PDF는 Tagged PDF가 아니므로 접근 가능한 PDF 인증을 주장하지 않는다.
