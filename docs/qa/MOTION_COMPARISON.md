# 모션·외형 비교표 (v3, V16 양식)

갱신: R9-a. 기준: [설계서 v3 부록 A·D](../REFACTOR_DESIGN_V3.md), [원본 관측 V02](../reference/MOTION_REFERENCE.md), [계약 v3](../CONTRACT_V3.md), `src/book/motion.ts`.

이 표는 세 출처를 **다른 열**에 둔다. 섞어 쓰지 않는다.

- **공개 코드 확인값**: 원본(Every Joule) 공개 번들의 정적 분석(설계서 부록 A). 실제 화면에서 잰 값이 아니다. 원본 소스·자산은 복사하지 않았다.
- **실제 영상 측정값**: 원본을 같은 시퀀스로 녹화해 잰 값. **결정 6(원본 녹화)이 제공되지 않아 모든 행이 '미측정'이다.** 이 열을 추정으로 채우지 않는다.
- **v3 채택값**: 이 저장소의 실제 값(토큰·코드)과, 있으면 headless 캡처 측정값. headless SwiftShader는 한 프레임에 0.5–3 s가 걸려 시간 측정은 실기기 값이 아니다.

차이 이유는 **독자 콘텐츠 / 접근성 / 모바일 가독성 / 권리 / 성능 / 불일치** 중에서 쓴다. '없음'은 공개 코드 확인값과 v3 채택값이 같은 값이거나 같은 방식이라는 뜻이고, 원본 체감 일치를 뜻하지 않는다.

## 남은 차이(불일치·미관측)

1. **먼/가까운 변 비율**: 부록 B 1번 기준 0.86–0.92에 대해 R9 기준선 0.857(1280×720) / 0.869(844×390) / 0.938(390×844). 계약 범위(C5: FOV 30–34°, 고도각 52–62°)의 끝값이며 1280×720은 하한에, 390×844는 상한에 못 맞는다. 범위를 넓히는 것은 계약 개정이므로 하지 않았다(R1 보고, R5 조작바 뒤 다시 잼).
2. **선 폭**: 서 있는 모서리 측정 2건이 범위 밖(R4 '부분 통과').
3. **모든 시간값**: 원본 실측이 없어 v3 시간 토큰은 제안값이다. 원본 녹화가 생기면 같은 시퀀스(열린 책 → 레슨 1 → 그림 등장 → 샷 → Next → Previous)로 이 표의 둘째 열을 채운다.
