## 실기기·청취·보조기술 미검수

| 항목 | 상태 |
|---|---|
| 실기기 | 모든 화면 검사는 Linux 컨테이너의 headless Chromium(SwiftShader WebGL, DPR 1)이다. iOS Safari·Android Chrome 터치, 회전, safe-area, 핀치, 60 fps 움직임, 발열은 보지 않았다. SwiftShader는 한 프레임에 0.5–3 s라 시간 측정·연속 장면은 inspector 시계 고정(`holdShot`·`holdFlaps`·`holdTurn`·`figureEntry`)으로 찍었다 |
| 청취 | 효과음 7종은 OfflineAudioContext 렌더로 길이·피크만 쟀다. 스피커·이어폰 청취(크기·질감·구별)는 외부 검수 대기 |
| 보조기술 | 거울 DOM의 구조·초점·라이브 문장은 자동 검사로 확인했다. VoiceOver·TalkBack·NVDA 실사용, 200% 확대 전체 감사는 하지 않았다 |
| 교육 | 여섯 펼침면의 문항·기보·정답·피드백은 단위 테스트(MU01–08)와 lesson 원문을 따른다. 음악 교육자 검토·학습자 파일럿·교육 효과는 미검증 |

## 품질 티어 (저티어 축소)

기기 판정(`src/book/profile.ts`): 휴대전화·태블릿 사용자 에이전트(데스크톱 모드 iPad 포함)는 low, 큰 캔버스(DPR² × CSS 픽셀 > 2.4 M)나 코어 4개 이하는 medium, 나머지는 high. `?quality=high|medium|low`로 고정할 수 있다. 내용·조작·소리는 세 티어가 같고, 그리는 비용만 줄인다.

| 항목 | high | medium | low |
|---|---|---|---|
| 후처리 | 렌더 · GTAO · SMAA · 비네트 · 출력 | GTAO 없음 | 후처리 없음(renderer MSAA + 톤 매핑) |
| 픽셀 비율 상한 | 2 | 1.5 | 1.25 |
| 그림자 맵 | 2048 | 2048 | 1024 |
| 쪽 인쇄 해상도(settled / draft / state) | 1280 / 768 / 512 | 1280 / 768 / 512 | 1024 / 640 / 512 |
| 잉크 그림 종이 면 해칭 | 켬 | 켬 | 끔 |

단계 캡처·기준선·성능 예산은 `?quality=high`, e2e는 자동 티어(이 컨테이너는 코어 2개라 medium 판정)로 돌렸고, low·medium은 R9에서 종이 음영 탐침으로 한 번씩 찍었다. low 티어의 실기기 화면(휴대전화)은 보지 않았다 — [사람 검수 패킷](qa/HUMAN_REVIEW_V3.md) 2장.

## 설계와 다르게 한 것

- 목차 → 레슨 같은 여러 장 넘김에서 **사이 쪽은 인쇄 없는 종이**로 지나간다(인쇄 창 6쪽 · ≤ 48 MiB 유지). 출발·도착 펼침면과 첫·마지막 잎의 보이는 면만 인쇄된다.
- 표지를 펼치면 **레슨 1**이 열린다(목차는 바로 앞 펼침면과 조작바 '목차').
- 2D 책의 레슨 쪽은 기존 `LessonPages.tsx`(같은 명령), 목차·마침만 쪽 DSL을 그리는 `MatterPages.tsx`다. 레슨 쪽까지 DSL 해석기로 바꾸지는 않았다.
- DEV inspector는 새 파일로 바꾸지 않고 R1–R8 동안 같은 파일을 v3 inspector로 고쳐 썼다.
