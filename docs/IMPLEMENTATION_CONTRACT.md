작성: 2026-10-26 UTC. 상태: **P00 준비 문서 작성, 로컬 입력 검증은 차단되어 P00 수용 게이트 미통과.**

## 제품 범위

1. `duration-basics` 한 단원, 한국어, 여섯 장면. 4/4, 4분음표를 한 박, C4=MIDI60, 기본 BPM90, 비교60/120.
2. 수준1~3은 앱, 수준4~5는 교사 확장 활동. 학습자 능력 등급으로 표시하지 않는다.
3. 분수 `{n,d}`의 정확 연산과 철자 보존 pitch를 정본으로 한다. 2D 악보·2D/3D 블록·오디오·평가는 같은 검증된 snapshot/revision을 사용한다.
4. 2D 학습 경로부터 구현한다. 정확한 악보 렌더러를 검증하며 근사 오선·이모지를 정답 악보로 쓰지 않는다. 3D X축은 상대 시간이고 높이·깊이는 일정하다.
5. 가로형 모바일 우선, 세로 및 낮은 높이 대체 필수. 방향 잠금·강제 fullscreen·핀치 줌 차단 금지. 주요 DOM 조작은 44×44 CSS px 이상, 키보드·터치·무음·2D 경로를 제공한다.
6. AudioContext.currentTime으로 예약하고 화면이 같은 시간을 읽는다. 사용자 제스처 전 자동 소리 없음. Stop·장면 이동·초기화·탭 숨김 시 미래 source까지 취소하며 위치0으로 복귀한다. 재생 중 편집·템포 변경 금지. Loop는 명시적 사용자 선택과 안전한 취소 검증을 요구한다. 일시정지·중간 재개는 MVP 범위 밖이다.
7. 장면1 총 길이·어택·속성 구별, 장면2 분할·인접 동종/동길이 병합·undo/redo, 장면3 동치 조합, 장면4 쉼표, 장면5 템포 비율, 장면6 조건부 한 마디와 설명을 구현한다.
8. 자유 설명은 AI·키워드로 정오 채점하지 않는다. 현재 답 유효성과 과거 달성·청취와 텍스트 대체 기록을 구별한다.
9. 로그인·서버·결제·생성형 판정·녹음·분석 추적을 넣지 않는다. 로컬 최소 기록, 버전 검증, 가져오기 미리보기·확인, namespace 내 삭제와 백업 삭제를 구현한다.
10. 교사 보기는 로컬 표시 모드이며 인증 경계가 아니다. 정답은 기본 숨김이고 학생 복귀 시 숨긴다. Canvas를 대신하는 실제 2D 인쇄를 검수한다.

## 보존과 권한

원설계서, 원본 음악·영상·ZIP·다른 프로젝트를 수정하지 않는다. Every Joule는 체험학습 원칙만 참고하며 코드·자산·브랜드·레이아웃을 복제하지 않는다. 권리·내용·청취가 미확인인 자산은 연결하지 않는다. 독자 도식과 prototype-synth를 계획할 수 있다.

로그인·권한 확대·유료 서비스·외부 공개 배포·도메인 연결·원격 저장소 push를 별도 허용 없이 수행하지 않는다. 현재 권한 밖 네트워크 접근을 다른 경로로 우회하지 않는다. 허용된 문서 전송 재시도는 이번 실행에서 이미 사용했다.
