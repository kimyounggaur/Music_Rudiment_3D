# 결정 0001 — 범위와 차단 게이트

상태: 준비 문서 기준의 구현 방향, 코드 미적용. 날짜: 2026-10-26 UTC.

사용자 지시에 따라 새 독립 폴더 music-theory-lab을 준비한다. 기존 프로젝트가 없어 재사용할 앱 스택/lockfile은 발견하지 못했다. 원본 문서를 수정하지 않는다.

설계서 대비 프롬프트가 구체화한 가로 우선과 세로 동등 대체, 장면별 레인, 합법적 draft와 playable/assessment 분리, 인접 동종·동길이 병합 역연산을 따른다. 각 결정은 데이터 모델과 수용 테스트에 함께 반영되어야 한다. 원본 설계 예시 JSON과 변경 구조를 같은 schema로 위장하지 않는다.

UI는 React+TypeScript, 3D는 R3F+Three 후보, Web Audio 직접 시간축, VexFlow 후보를 P03에서 실제 비교한다. 현재 정확 버전·API·라이선스·peer dependency·renderer 결과를 검증하지 못했으므로 선택 완료라고 하지 않는다. npm 하나를 우선 후보로 삼되 lockfile은 아직 없다.

네트워크가 차단된 상태에서 CDN 의존 데모·가짜 package version·항상 성공하는 테스트 스크립트·근사 악보를 만들지 않는다. 이는 미실행 산출물을 완료로 표시하지 말라는 사용자 및 프롬프트 게이트를 지키기 위한 결정이다.

반복 재생은 사용자가 검증 항목으로 요청했다. P09에서 Loop on/off, 한 활성 세션, 마디 경계, 정지/장면 이동/숨김 시 미래 반복 예약까지 취소하는 정책을 구체화한다. 프롬프트의 일시정지 없음·정지 위치0 정책을 유지한다.

P23은 확장 구현의 자동 허가가 아니다. 첫 파일럿 QA가 확보되고 다음 단원 한 개가 선택되기 전에는 공통 모듈 재사용 분석과 계획 범위를 넘지 않는다.
