# 결정0002 — 원형입력과실행검증상태분리

부모의추가지시로Library원형파일확보실패와요구사항원격읽기를분리하고,독립가능한코드를구현했다. P03의원격패키지실패를통과로바꾸지않았으며기존로컬도구로domain테스트부터실행한뒤React통합까지확장했다.

Three/VexFlow는로컬에없어Three표현은CSS3D로대체했다. 정확한기보는대체근사로만들지않고P07미완료를유지했다. R3F/Three의원래선택과동등검증했다고주장하지않는다.

localhostEACCES연결거부후그대상/다른port/권한확대를시도하지않았다. 독립파일HTML을생성하여네트워크요청이없는file-origin화면을검증했다. 이것은HTTP서버E2E의통과가아니다.

다운로드canceled실패를그대로보존하고,별도JSON원문보기를제공해다운로드접근없이유효최소데이터를확인·선택할수있게했다. 실패다운로드가수정됐다고보고하지않는다.

자동검증이통과해도실제음악/청취/기기/사용성승인을임의생성하지않는다.
