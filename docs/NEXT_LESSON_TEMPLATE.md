# 다음 단원 분석 양식

이 문서는 재사용 가능성을 검토하는 양식이다. 사용자가 다음 단원을 선택하지 않았고 첫 단원의 Three/HTTP 경로·실기기 청취·교사 파일럿 검증이 남아 있으므로, 다음 단원을 승인되거나 구현된 것으로 취급하지 않는다. 첫 단원의 실제 VexFlow 5 악보 연결은 구현되었지만 교육자 검수를 대신하지 않는다.

## 후보 명세

| 필드 | 작성 내용 |
| --- | --- |
| 후보 단원명·고유 ID | 미선정 |
| 연결된 원본 설계·버전 | 미선정 |
| 선행 개념 | 첫 단원 파일럿에서 확인할 선행 학습 조건 |
| 핵심 질문·오개념 | 시간·소리·기보 사이에서 정확히 무엇을 구분할지 |
| 목표 행동·완료 근거 | 조작 결과, 개념 답변, 설명/교사 확인의 구분 |
| 최소 장면 흐름 | 관찰 → 조작 → 표현 연결 → 비교 → 창작 → 확인 등 후보만 작성 |
| 텍스트·무음 대체 | 청취와 구분되는 동일 개념의 접근 경로 |
| 교사 파일럿 기준 | 관찰 항목·실패 조건·수정 후 재검증 기준 |

## 재사용 후보와 현재 단원 고정

| 영역 | 재사용 후보 | 추가 분석이 필요한 고정 |
| --- | --- | --- |
| 분수·음악 계산 | 유리수, 음높이·주파수, 박자·기보 길이, 초 변환 | 새 단원에서 필요한 박자·음가·음높이 범위와 오류 한계 |
| AudioEngine | 불변 snapshot, Web Audio 시간 예약, 반복·중단, 음량 | 다성·음색·아티큘레이션·실제 악기 샘플은 별도 설계/검증 |
| 2D/CSS 입체 | 이벤트 시간 비율·안정 ID·선택 목록 | 높이/깊이에 새 음악적 의미를 주면 기존 오개념 안내를 그대로 쓰지 않음 |
| 정확 악보 adapter | 실제 VexFlow 5 SVG·내장 폰트, 이벤트 강조·폭 변경·폰트 오류 재시도 | 현재 실제 기보 23개·폰트 재시도 1개 확인 범위. 새로운 박자·점/잇단·조표 범위는 별도 콘텐츠와 fixture 검증 필요 |
| lesson/controller | 순수 명령·검증·undo/redo 구조 | scene ID, 6장면 완료 분기, 레인·편집 허용·템포가 현재 단원에 고정 |
| 콘텐츠 검증 | 오류 경로·분수·기보 일치 검사 | `duration-basics`, schema/content 버전, C4·4/4·음가 범위가 현재 단원에 고정 |
| 저장·JSON | 미리보기/확정, 안전한 검사, 원본 기록 보존 | lesson ID·저장 키·6장면·9레인·C4·지원 버전·허용 event 수가 고정 |
| 평가·UI | 개념별 피드백·교사 안내·대체 UI | 현재 문항·정답·완료 규칙·내비게이션 상한을 새 계약으로 작성해야 함 |

## 설계 검토 산출물

새 후보마다 독립적인 콘텐츠 계약, 데이터/저장 버전 전략, 조작 명령과 불변식, 악보 기준 fixture, 실제 청취 비교표, 접근성 대체 흐름, 단위/통합/브라우저/교사 검수 계획을 작성한다. 기존 사용자의 진행 파일은 명확히 버전을 나누며 알려지지 않은 이관을 추측해 만들지 않는다. VexFlow 및 내장 폰트의 MIT/OFL 고지를 보존하고 CSS 입체 표현을 Three/WebGL 검증으로 바꾸어 설명하지 않는다.

첫 단원의 수용 테스트와 파일럿이 확인되기 전에는 양식을 채운 사실만으로 다음 단원 제작에 착수하거나 다음 단원 버튼·샘플 콘텐츠를 완성 기능처럼 추가하지 않는다.
